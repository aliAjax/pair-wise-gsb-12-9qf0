# 故障救援与转派台（车辆调度小工具扩展）

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia（不增加任何新依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

- 车辆故障后**冻结里程**（读数保留、不可修改），只有「维修完成并解冻」后才能恢复派车。
- 接管车辆必须同时通过：**剩余货重 ≤ 额定载重、温区与所有剩余停靠点一致、班次一致、
  司机连续驾驶不超过 4 小时、车辆空闲未占用、里程未冻结**。
- 连续驾驶超四小时或温区不符（以及其余任一项不通过）时**整单拒绝并保留原派单**，
  原里程不冻结、任务不换车，仅登记一条拒绝记录。
- 转派成功后写入救援记录：**故障位置、故障原因、救援费、冻结里程、升级说明**，
  新车**继承剩余线路**，任务版本 +1（首次派车为 v1）。
- 同一任务**再次故障必须填写升级说明**，否则整单拒绝。
- 刷新页面后任务、车辆占用、救援记录与版本号通过 localStorage 保持一致。
- 异常中心按 **任务 / 车辆 / 超重 / 温区 / 规则** 五类列出全部派生异常。

## 分层结构（数据、判定、页面分开）

- `src/data/`：类型（`types.ts`）、种子数据（`seed.ts`）、localStorage 存取（`storage.ts`）。
- `src/domain/rules.ts`：纯函数规则引擎——接管校验、升级判定、异常检测、版本时间线，
  不依赖 Vue / store / DOM。
- `src/stores/dispatch.ts`：Pinia store，所有状态变更的唯一入口，保证任务、占用、救援、版本原子一致。
- `src/components/`：页面组件（任务表单、任务看板、救援转派台、车辆面板、异常中心、救援记录）。
