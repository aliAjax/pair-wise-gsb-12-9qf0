# 故障救援与转派台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在车辆调度小工具基础上扩展的故障救援与转派控制台：

- 故障登记后车辆里程冻结，任务进入待转派，原派单保留；
- 仅余货重、温区、班次校验通过的空闲车辆可接管，接管后继承剩余线路；
- 司机连续驾驶超 4 小时或温区不符时整单拒绝，保留原派单；
- 转派记录故障位置、原因、救援费与剩余线路快照；
- 再次故障必须填写升级说明，任务自动生成新版本；
- 异常清单实时列出任务、车辆、超重、温区与规则问题；
- 刷新后任务、车辆占用、救援记录与版本自动对齐（localStorage 持久化 + 加载时 reconcile）。

## 代码结构

- `src/data.ts`：数据层，类型、种子数据、本地持久化；
- `src/rules.ts`：判定层，接管校验、整单拒绝、异常收集、一致性修复（纯函数）；
- `src/App.vue`：页面层，只做交互与渲染。

未新增任何依赖。
